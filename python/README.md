# deepfriend (Python)

Companion package of the **DeepFriend** VS Code extension.
Inside VS Code you do not need to install this — the extension bundles it.
Install it only for Jupyter or terminals outside VS Code:

```bash
pip install deepfriend
```

```python
import deepfriend
deepfriend.watch()   # training doctor + automatic experiment log
```

See https://github.com/mrpark10/DeepFriend for documentation.
