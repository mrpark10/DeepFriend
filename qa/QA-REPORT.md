## 3. 인수 테스트 (명세서 완료 기준)

| 명세 항목 | 기준 | 결과 · 근거 |
|---|---|---|
| F1 크기 표시 | 저장 후 1초 안 | 77 ms (`f1.test.ts` "hints update within 1 second") |
| F1 정확도 | 지원 레이어에서 실제 실행과 100% 같음 | 무작위 조합 대조: torch 레이어 5,000개씩·Keras 1,000개 모델 불일치 0. 실전 모델 코퍼스(ResNet·U-Net·VGG·TextCNN·오토인코더·어텐션) 줄 단위 일치 (`test_corpus.py`), RNN/어텐션 대조 (`test_rnn_parity.py`) |
| F1 에러 | 빨간 밑줄 + 한국어 설명 + 빠른 수정 | 명세 예문 그대로 확인, 빠른 수정 적용 후 밑줄 사라짐 |
| F2 학습 닥터 | 5가지 상황을 예제에서 모두 맞게 진단 | NaN·과적합·정체·출렁임·찍기 5/5, 정상 학습 오진 0 (seed 5개 반복 검증) |
| F2 시작 방법 | `import deepfriend; deepfriend.watch()` 한 줄 | VS Code 터미널에서 pip 설치 없이 동작 (`acceptance.test.ts`) |
| F3 에러 해설 | 크기·CUDA 메모리·dtype·장치·모듈 없음 오프라인 사전 | 실제 torch/tf 에러 원문 25종 + 합성 6종으로 검증 |
| F4 모델 구조 | 블록·파라미터 수·메모리, 클릭 이동, 연동 | LeNet 7블록·61,706개 정확, 커서 연동, 클릭 이동 |

| F7 개념 설명 | 호버 + 매개변수 + 난이도 | 42개 개념, 입문/보통, 한/영 |

## 4. QA 중 발견하고 고친 오류

1. MaxPool padding 제한 규칙이 PyTorch와 달랐음 (대조 테스트로 발견)
2. meta 장치 에러 문구가 CPU와 달라 크기 에러를 놓침
3. 샌드박스가 torch 내부의 임시 폴더 확인을 막아 런타임 검사가 항상 실패
4. Python 서버 "최신 요청만" 테스트가 타이밍에 따라 흔들림 → 결정적 테스트로 교체
5. meta.json만 바뀌면 학습 닥터 화면이 갱신되지 않음
6. 실행 중인 학습에 별표를 누르면 파이썬이 덮어써서 사라짐
7. 웹뷰: 좁은 폭에서 넘침, 아주 큰 loss의 y축 잘림, 범례 "--", 샘플이 너무 작음
8. 그림 안 한국어가 영어 모드에도 나옴 → 한/영 두 벌
9. 학습 닥터 스니펫이 영어 모드에서도 한국어
10. 예전에 컴파일된 테스트 파일이 남아 지운 기능의 테스트가 돎 → 테스트 전 out 정리
11. 터미널 테스트가 zsh 고정 → OS별 셸
