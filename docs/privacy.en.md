# DeepFriend Privacy Policy

Effective: October 26, 2026 · Operator: Junho Park (sk92977852@gmail.com)

1. **No data collection.** The developer collects no personal data and runs no servers. There is no telemetry, analytics or advertising.
2. **Stored on your computer.** For runs using `deepfriend.watch()`, settings, metrics, a copy of your training code and a few tiny data samples are stored in your project's `.deepfriend/` folder (with an automatic `.gitignore`). Delete it any time or turn off `deepfriend.autoRecord`.
3. **Optional AI.** If you choose an AI provider, error text with at most 10 related code lines, or diagnosis sentences, are sent only after you approve the exact content, to the provider you chose (VS Code built-in AI/GitHub Copilot, Anthropic, or your OpenAI-compatible endpoint), under that provider's policy. API keys live only in VS Code SecretStorage.
4. **Bug reports** open a prefilled GitHub issue that you review and submit yourself; home-directory paths are masked.
5. **Contact:** sk92977852@gmail.com or https://github.com/mrpark10/DeepFriend/issues
